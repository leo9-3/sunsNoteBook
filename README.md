# 内网纪要本 · Intranet Notebook

公司内网可用的笔记软件：**按日期新建纪要 + OneNote 式自由画布**。在一篇纪要里，文字块、标题、便签、待办和图片都可以放在画布任意位置，自由拖动、缩放、组合，不受文档流式排版限制。

选型调研见 [docs/OPEN_SOURCE_RESEARCH.md](docs/OPEN_SOURCE_RESEARCH.md)（对比了 AFFiNE / tldraw / Excalidraw / Trilium 等，结论：现成最接近的是 AFFiNE Edgeless，但部署重、tldraw 生产需付费授权，所以做了这个零依赖轻量版）。

## 功能

- 📚 **合集（笔记本）**：最左侧是 OneNote 式合集栏——内置「日记」合集按日期管理（下面这条），点「＋ 合集」可新建自由合集（如「学习」「工作」），里面是按标题的页面（新建/改名/搜索/删除，最新编辑在前）；合集可双击改名、悬停 ✕ 删除（连同页面），日记合集不可删；旧数据升级后自动全部归入日记合集
- 🗂️ **合集内文件夹**（v0.6.0）：自由合集里可建文件夹分类（如「2026 会议」「部门培训」），左侧呈可折叠的树：点文件夹展开/收起，文件夹行上的 ＋ 直接在夹内新建页面，双击改名，✕ 删夹时页面移回根目录不丢失。若页面提示「服务端还是旧版本」，说明旧程序还在运行——用安装文件夹里的 `stop-windows.bat` 彻底关掉旧程序再重开即可
- 👋 **关页自动退出**（v0.7.0）：页面开着时每 5 秒向服务端发一次心跳；关掉最后一个页面后，服务端约 8 秒后自动退出，不再留后台进程占端口（刷新页面不会误杀，新页面的心跳会取消退出；页面崩溃则由 150 秒无心跳兜底退出）。多人共用的服务器部署如需常驻，启动前设环境变量 `NOTEBOOK_NO_AUTOSTOP=1` 即可禁用
- 🌳 **拖边框缩放 / 图片全屏 / 随笔层级**（v0.8.0）：文本框与图片框可拖四边边框单向扩大（文本框为左右两边，高度随内容），拖右下角同时扩大两个方向；双击图片（图片框或正文内嵌图）全屏查看，点任意处或 Esc 退出；自由合集里右键点一篇随笔可「新建同级笔记 / 新建下级笔记」，建了下级的随笔自动变文件夹图标并可折叠展开，删掉上级时下级自动上提一级不丢失
- ✏️ **画笔涂鸦**（v0.9.0）：点工具栏「✏️ 画笔」进入绘画模式，可在页面任意位置（包括文字、图片上方）自由画线圈注，5 种颜色、3 档粗细，另有橡皮擦（点中或划过一笔即擦掉）；每一笔落下后自动成为一个独立的块，可选中、拖动、缩放、删除，和 OneNote 的墨迹一样
- 🩹 **画笔修正**（v0.9.1）：修复细笔画被块的最小尺寸撑变形、导致红线与鼠标位置对不上的问题；笔迹块右上角 ✕ 现在能正常删除；退出画笔后选中任意块按 Delete/Backspace 即可删除；画笔模式下支持 Ctrl+Z 撤销、Ctrl+Y 重做（笔条上也有撤销/重做按钮），擦掉的笔画也能撤销回来
- 📱 **安卓版**（v0.10.0）：新增 `android/` 工程，可把同一套网页前端打包成安卓 APK（WebView 壳，见 `android/build.sh`），装到手机上离线使用：无服务端时自动用手机本地存储，数据保存在 App 内；支持手指拖动、手指画笔（触摸事件转译），插图走系统相册选择，导出 JSON 直接存到手机下载目录。手机适配同时修了两个通用问题：前端资源改为相对路径（file:// 下也能打开）、无服务端模式下重开合集会误建空白页
- 📱 **小屏布局**（v0.10.1）：屏幕宽度 ≤820px 时自动切换手机布局——合集栏缩成图标、笔记列表变成从左侧滑出的抽屉（顶部「☰ 列表」开关，选完笔记自动收起）、工具栏/格式栏/笔条改为单行横向滑动，画布拿满剩余宽度（390px 竖屏实测：画布从 18px 宽恢复到 338px）。桌面宽屏不受影响
- 📅 **按日期管理**：一键新建今天的纪要（新建即落库并聚焦标题栏）；日期选择器打开任意一天；左侧年/月/日三级日期树（可折叠，按日期正序）+ 搜索；顶部标题栏给纪要命名，树上双击可改名，每篇可删除（顶部“删除本篇”或树上 ✕，均有确认）；画布或左侧栏空白处**右键**可在屏幕中央弹出日历，点任意一天即新建/打开；新纪要默认名为“XX日 星期X”（如“17日 星期二”），可改名；文字块默认贴合内容宽度，选中后拖右下角可改成任意宽度（文字自动换行），双击右下角恢复自动宽度
- 📊 **简单表格**：工具栏“＋ 表格”插入 3×3 表格，单元格直接打字，块顶部可 ＋行/－行/＋列/－列，第一行自动加粗作表头
- 🖼️ **自由画布**：双击任意处加文字；工具栏加标题/便签/待办；图片可点选上传、拖拽拖入、Ctrl+V 直接粘贴截图；**在文字块里编辑时插入图片会嵌进文字中间**（落在光标行，空白行直接替换），随文字一起排版，点选后可拖右下角调宽度、按 Delete 删除；拖图片文件到文字块上也会嵌到最近一行
- 🖱️ **滚轮滚动**：内容超出一屏时滚轮上下滚动页面，Ctrl+滚轮在光标处缩放；右键菜单里可“在右键处插入文本框/图片”
- ✒️ **格式栏**：选中文字可切换字体（宋体/黑体/楷体/仿宋等）和正文/标题 1/2/3 等级（按行生效，和 Word 的标题样式一样；快捷键 Ctrl+Alt+0/1/2/3）；字体颜色（6 个预设色 + 自定义取色 + 默认色）可**逐字**设置——选中几个字就染几个字，v0.2.8 的整行颜色会自动迁移
- 🔥 **补丁热升级**：后续更新发小体积补丁包，解压覆盖到原安装目录即可，数据（data/）和运行环境（runtime/）都不动；页面文件每次打开现读，覆盖后刷新浏览器即是新版，一般不用重启服务（详见包内 UPGRADE.txt）
- 🖱️ 每个块可拖动到任意位置、拉右下角缩放；画布可平移、缩放
- 💾 自动保存到本地 SQLite 数据库 `data/notebook.db`（Node 内置，零依赖）；旧版按天 JSON 首次启动自动导入；可导出单篇 JSON
- 🔒 **纯内网**：零 npm 依赖、零外网请求，不需要账号，数据不出公司网络

> **隔离内网部署**：不用 GitHub/npm/Docker 拉取，直接用离线安装包（内置 Node 运行时，免安装免联网），见 [docs/OFFLINE_INSTALL.md](docs/OFFLINE_INSTALL.md)。

## 快速开始

```bash
# 需要 Node.js >= 18（内网离线也能跑，不用 npm install）
node server.js
# 打开 http://localhost:4173
```

Docker（内网服务器）：

```bash
docker compose up -d
# 打开 http://服务器IP:4173
```

## 目录

```
server.js          # 零依赖 Node 服务 + REST API (/api/notes)
public/            # 前端：index.html / app.js / style.css
data/              # 本地 SQLite 数据库 notebook.db（已 gitignore 内容）
docs/              # 选型调研
```

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/notes` | 全部纪要列表（日期、标题、块数） |
| GET | `/api/notes/2026-11-16` | 打开某天，没有则返回空白模板 |
| PUT | `/api/notes/2026-11-16` | 保存 `{title, elements:[{id,type,x,y,w,h,text/src}]}` |
| DELETE | `/api/notes/2026-11-16` | 删除某天 |
